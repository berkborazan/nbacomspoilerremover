# NBA.COM News Spoiler Remover
Violentmonkey, Greasemonkey, Tampermonkey script for removing news section from the NBA's main page which gives you actual spoilers about the games.

## To Install:
Install Violentmonkey or Greasemonkey or Tampermonkey.
Select the new user script.
Copy and paste the JavaScript code.
Have fun.

## Current Functions:
- Hides the news of the opening page.
